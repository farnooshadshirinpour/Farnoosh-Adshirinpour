Featured project

Interactive Spatial Drawing Assistant

A prototype built in Unity 6 and C#. A user traces the four sides of a predefined rectangle in a 3D scene. The system compares each stroke with its target edge, records how far the stroke strays, and reports feedback messages in real time while the user draws.

I built it to treat drawing as an interaction that a system can represent, measure, and support, and to carry the perspective, form, and depth I work with as an artist into a computational setting.

How it works

  1. The scene defines the target as four points on one plane. Each side is 4 Unity units long.
  2. The user draws each edge with the mouse. Strokes are captured as point sequences and rendered with Unity's LineRenderer as a separate UserDrawing line, so the drawn stroke stays visually distinct from the target.
  3. The system measures the Euclidean distance between the drawn points and the corresponding target edge in 3D coordinates.
  4. For each edge it records average deviation and maximum deviation. The average shows overall accuracy, and the maximum exposes local errors the average hides.
  5. Corner-tolerance checks and side-completion detection track whether the user is progressing through the rectangle in order.

What testing showed

I tested the prototype with my own drawing attempts, recorded deviation for each edge, and refined the interaction during testing.

Average and maximum answer different questions

In the first test, edge CD averaged 2.1 deviation but reached a maximum of 10.0. A stroke that is accurate overall can still contain one large error, and a single accuracy score would hide it.

Reaching a target is not the same as following the path

In some attempts the system moved on to the next side as soon as I reached a corner, even though the stroke before it had drifted from the path. Arriving at a target and following a path accurately are separate problems, so completion checks need to look at the movement as well as the endpoint.

Accuracy varied between attempts

Edge BC averaged 3.7 in the first test and 9.4 in the second, with its maximum rising from 7.0 to 13.0.
